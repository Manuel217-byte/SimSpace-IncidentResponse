# SimSpace-IncidentResponse
Files on hand-on incident response and digital forensics using the SimSpace platform

A suspected phishing incident involving a malicious email sent to an Internal Communications employee. The email used a legitimate looking calendar submission request to direct the user to an unfamiliar domain. Which resulted in a executable download. SIEM and endpoint activity indicated suspicious network connections and unusual processes. 

Tools used for incident response and digital forensics: FTK Imager, KAPE, Registry Explorer, LECmd, JLECmd, PECmd, Volatility, Dumpit, tcpdump, NetworkMiner, Zeek, Splunk Enterprise, Event Log Explorer, and Velociraptor
